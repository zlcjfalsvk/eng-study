Adaptation: cheolcheol / Eng, 2026-10-27.
English large wordlist Zipf estimates were used to order Eng headwords.
An editorial core list is placed first for each level. Remaining multi-token
headwords have a 1.0 Zipf-point editorial penalty. Ties use headword then ID.
Phrase estimates use component words, not observed counts of whole phrases.
The source reflects usage through about 2021, not current live frequency.
Frequency is not sense-specific, domain-specific, or a CEFR assessment.
These attributions and terms apply to the derived ranking dataset; no license
change is asserted for independently authored definitions or example content.

notice below. SUBTLEX data remains freely available:
